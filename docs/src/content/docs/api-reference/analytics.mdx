## Overview

The Analytics API provides access to organization dashboards, agent performance tracking, and direct Meta WhatsApp platform metrics.

---

## Dashboard Stats

Retrieve general high-level dashboard metrics for the organization.

```bash
GET /api/analytics/dashboard
```

### Query Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `from` | string | No | Start date (`YYYY-MM-DD`). Defaults to start of current month. |
| `to` | string | No | End date (`YYYY-MM-DD`). Defaults to current date. |

### Response

```json
{
  "status": "success",
  "data": {
    "stats": {
      "total_messages": 12450,
      "messages_change": 14.5,
      "total_contacts": 450,
      "contacts_change": 8.2,
      "chatbot_sessions": 890,
      "chatbot_change": -3.1,
      "campaigns_sent": 12,
      "campaigns_change": 20.0
    },
    "recent_messages": [
      {
        "id": "e9b728cd-7eb1-4d32-9cb7-7f8a7e02e1c0",

        "direction": "incoming",
        "created_at": "2024-01-01T12:00:00Z",

}
```

## Agent Analytics

Track performance metrics, response times, and break records for support agents. 

<Aside type="note">
  Regular agents only see their own statistics (`my_stats`). Administrators and Managers see metrics for all agents.
</Aside>

### List Agent Analytics

```bash
GET /api/analytics/agents
```

#### Query Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `from` | string | No | Start date (`YYYY-MM-DD`). Defaults to start of current month. |
| `to` | string | No | End date (`YYYY-MM-DD`). Defaults to current date. |
| `group_by` | string | No | Trend grouping: `day` or `week` (default: `day`) |
| `agent_id` | string | No | Filter by specific agent UUID (requires administrative permission) |

| `group_by` | string | No | Trend grouping: `day` or `week` |

## Meta WhatsApp Analytics

Directly queries Meta's Graph API for phone-level performance metrics, templates click rates, cost, and pricing tier information. Results are cached to avoid API rate limits.

### Get Meta Analytics

```bash
GET /api/analytics/meta
```

#### Query Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `analytics_type` | string | Yes | Metrics type: `analytics`, `pricing_analytics`, `template_analytics`, `call_analytics` |
| `start` | string | Yes | Start date (`YYYY-MM-DD`) |
| `end` | string | Yes | End date (`YYYY-MM-DD`) |
| `account_id` | string | No | Filter by specific WhatsApp Account UUID (queries all WABAs if empty) |
| `granularity` | string | No | Granularity: `HALF_HOUR`, `DAY`, `MONTH` (default: `DAY`). Auto-adjusted per API rules. |
| `template_ids` | string | No | Filter by template IDs (JSON array of strings, e.g. `["123","456"]`) |

#### Response (Messaging Analytics example)

```json
{
  "status": "success",
  "data": {
    "accounts": [
      {
        "account_id": "893c5d88-b4b6-4b2a-bf3b-9a8bb698a3e7",
        "account_name": "Primary Line",
        "data": {
          "id": "1234567890123",
          "analytics": {
            "granularity": "DAY",

                "start": 1704067200,

                "sent": 150,
                "delivered": 148
              }
            ]
          }
```

```json
  }
}
```

### List Meta Accounts for Analytics

List active WhatsApp phone numbers/accounts configured for queries.

```bash
GET /api/analytics/meta/accounts
```

#### Response

```json
{
  "status": "success",
  "data": {
    "accounts": [
      {
        "id": "893c5d88-b4b6-4b2a-bf3b-9a8bb698a3e7",
        "name": "Primary Line",
        "phone_id": "123456789"
      }
    ]
  }
}
```

### Refresh Meta Cache

Clear the Redis cache for all cached Meta analytics configurations belonging to the organization.

```bash
POST /api/analytics/meta/refresh
```

#### Response

```json
{
  "status": "success",
  "data": {
    "message": "Analytics cache cleared successfully"
  }
}
```
